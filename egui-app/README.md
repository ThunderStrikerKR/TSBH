# BANDO HUB — egui UI 재구축 1단계

현재 `main`에 존재하는 **독립 실행 UI 골격**이다. 사용자가 제공한 2026-11-19 React 접수 캡처와 `docs/egui-ui-design-contract.md`를 기준으로 한다.

## 실행

Rust toolchain 설치 환경에서 저장소 루트 기준:

```powershell
cargo run --manifest-path egui-app/Cargo.toml
```

현재 이 실행파일은 **UI 구현을 위한 독립 프리뷰**이고 React/Tauri 운영 앱을 대체하지 않는다. SQLite DB에 접속하지 않고, 공장 연동·주문 저장·Kakao 도킹 등 실제 업무 명령을 수행하지 않는다. 관련 버튼은 연결되기 전까지 비활성화한다. 현재 코드가 Windows에서 빌드·실행됐다는 주장은 하지 않는다.

## 구현된 UI 기반

- 역할별 테마 토큰(다크 색상, 글꼴·간격·모서리·버튼 스타일), Windows 한글 폰트 로딩
- 전역 8개 탭과 카카오톡 / 발주원문·복사용 자동 메시지 / 확인·수취인·품목 / 처리 중인 주문의 4열 레이아웃
- 네비게이션 전환, 독립적 카카오톡·주문 목록 측면 패널 크기 조절, 빈 발주원문 표시
- **별도 UI 샘플 모드**: 사용자 제공 캡처의 시험 주문을 모사해 글씨/표/상태등의 정보 밀도를 비교한다. 샘플 데이터는 메모리에만 존재하며 업무 로직이나 DB와 무관하다.
- 실제 연결 전 기능은 비활성화 및 ‘UI 프리뷰’ 상태 표시. 작동하는 것처럼 꾸미지 않는다.

## 현재 의도적으로 미구현

- React/Tauri 교체, Rust 업무 엔진 IPC와 SQLite 연결, 데이터 저장, 원문 파싱·하이라이트, 카카오톡 외부 Windows 창 연동
- 중간 2열 비율 드래그, 하단 수평 분할, 주문 카드 실사용 편집, 나머지 7개 화면의 전체 기능
- Windows 실제 DPI와 색·글자 높이 대조

## 보호 대상

`backup/main-before-egui-20261119`를 수정하지 않는다. 운영 DB/설정/실행파일 백업은 Git 브랜치와 별도로 필요하다.
